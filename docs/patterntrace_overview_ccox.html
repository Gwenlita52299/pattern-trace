工程基线

质量门禁与安全设计

质量门禁

  • verify_phase6.sh：发布前一键收口（测试 / E2E / 契约 / 性能 / 配置）
  • 契约测试 CT-01~03：OpenAPI 快照守护、404 稳定性、悬空边拒绝
  • E2E 业务闭环：登录→建案→关联地址→分析→导出，全程 mock 不依赖公网
  • CI 三 job：后端 lint/test/codegen 守护、前端 type-check、compose 冒烟；nightly 追加 PERF 性能档
  • D3 ID 反向校验：每条 evidence 必须闭合于子图节点/边 ID 集

安全基线

  • 密码哈希：bcrypt cost 12（存量 pbkdf2 平滑兼容）
  • 令牌体系：access 15min + refresh 7d rotation，reuse detection 存 Redis 原子执行；refresh 仅经 HttpOnly Cookie，绝不出现在响应 body
  • CSRF：写请求服务端强制校验 X-Requested-With
  • CORS：显式白名单，allow_credentials 下禁止通配符
  • 越权隔离：非本人资源一律 404 并落审计日志
  • 报告下载：HMAC-SHA256 签名 URL，15 分钟过期

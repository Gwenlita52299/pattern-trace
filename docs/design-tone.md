# PatternTrace · 设计调性规范 v1（grill-me 钉死版）

> 2026-09-05 通过三轮 grilling 确认，是所有 UI 决策的上位依据。

## 一句话调性

**全暗取证实验室**——冷静的卷宗工具，琥珀色只出现在「证据」上。
不是系统监控面板（demo-18 那类健康感不符合主题），不是赛博炫技，不是健康主题。

## 已锁定的 11 项决策

| # | 维度 | 决策 |
|---|------|------|
| 1 | 核心调性 | 取证感 + 追凶感（法庭卷宗气质 + 情报工具气质的混合） |
| 2 | 使用节奏 | 调查员每天几十上百次初筛 → 信息密度高、快、眼睛不累，酷炫排第二 |
| 3 | 高危警示 | 极克制：永不闪烁、永不红色铺底，专业软件不做情绪化警示 |
| 4 | 首要观众 | 面试官 + 技术叙事 → 专业可信优先于视觉冲击 |
| 5 | 明暗基调 | 全暗色 |
| 6 | 主配色 | 冷灰炭（graphite）+ 琥珀（amber）作唯一强调色 |
| 7 | 追凶隐喻 | **案件卷宗**：地址=嫌疑人，pattern 命中=前科匹配，证据带编号（EX-01），页面结构像卷宗 |
| 8 | 四档风险编码 | 微色彩编码：小圆点/细描边 + 文字标签；大面板永远冷静 |
| 9 | 字体 | 界面无衬线；地址/金额/TXID/评分/时间戳全部等宽（mono） |
| 10 | 琥珀密度 | **琥珀 = 证据**：只用于 verdict 结论、命中 pattern、证据引用、高危标记；看到琥珀=有发现 |
| 11 | 执行路径 | 按此调性重做核心页面 demo（初筛台/图谱分析/案件卷宗/pattern 档案），评审后再迁移 Next.js |

## 色彩 token（草案，demo 中先行验证）

```css
--bg: #0e1116;          /* 冷灰炭底 */
--panel: #141920;       /* 面板 */
--panel-2: #181f28;     /* 悬浮层 */
--line: rgba(255,255,255,.07);
--ink: #e6e9ef;         /* 正文 */
--muted: #8b93a1;       /* 次级文字 */
--amber: #f0b429;       /* 证据色：verdict 命中 / pattern / 证据引用 / 高危点 */
--amber-hi: #ffd166;    /* 证据高亮 */
--risk-medium: #5b9dff; /* medium 档微编码 */
--risk-dim: #8b93a1;    /* low / no_match 中性 */
--font-ui: -apple-system, "SF Pro Display", "PingFang SC", sans-serif;
--font-mono: "SF Mono", "JetBrains Mono", Menlo, monospace;  /* 所有数据 */
```

## 禁止清单（违反即偏离调性）

- ❌ 红色警报横幅、闪烁、脉动的威胁动画
- ❌ 彩虹渐变、霓虹发光标题
- ❌ 「系统健康 / 吞吐量 / 服务监控」类文案与指标
- ❌ 大面积琥珀（琥珀永远是小面积、点睛式出现）
- ❌ 数据字段用非等宽字体

## 语义命名（替代通用仪表盘词汇）

- 地址 → 嫌疑人/标的地址
- pattern 知识库 → 前科档案库
- 命中 → 前科匹配（附相似度评分）
- 证据引用 → EX-01、EX-02…（物证编号）
- 案件 → 卷宗（case dossier）
- 四档 verdict → 裁决（high/medium/low/no_match 微编码）

# PatternTrace 演示视频脚本（约 90 秒）

> 目标：展示「地址 → 子图 → AI 判断 → 可视化 → 案件报告」完整闭环。
> 录制前准备：`docker compose up -d`，种子案例就绪
> （`LLM_PROVIDER=mock GRAPH_DATA_MODE=fixture python -m backend.services.seed_cases`）。

## 分镜

| # | 时长 | 画面 | 口播 |
|---|------|------|------|
| 1 | 0–8s | 登录页 → 输入演示账号进入首页 | “PatternTrace 是一个比特币洗钱模式溯源平台。” |
| 2 | 8–20s | 首页点击演示 chip「Lazarus 种子地址」→ 分析页 | “输入任意地址，系统在数秒内构建受控交易子图——深度最多三跳、规模自动裁剪。” |
| 3 | 20–38s | 图谱画布：滚动缩放、点击节点详情、切换“深度 ≤L1”过滤 | “画布按层布局，红色边代表 remix 行为，⚠ 红框标记已知混币器，虚线表示停止扩展的交易路径。” |
| 4 | 38–55s | 右侧 Verdict 面板：risk=high、匹配 Lazarus Cluster、置信度、evidence 点击高亮对应节点 | “检索引擎从知识库召回相似模式，LLM 输出结构化结论；每条 evidence 都能反向定位到图中节点，杜绝模型幻觉引用。” |
| 5 | 55–72s | 新建案件 → 关联该地址 → 案件列表显示状态流转 | “调查人员可以建立案件、批量关联地址，全流程写入审计日志。” |
| 6 | 72–85s | 案件详情导出 PDF → 打开报告（含子图哈希、模型版本、逐地址结论） | “报告异步生成，签名链接 15 分钟内有效，内嵌完整证据链。” |
| 7 | 85–90s | 结尾 logo + 公网地址 | “PatternTrace——让每一笔可疑资金都有迹可循。” |

## 录制清单（Checklist）

- [ ] mock provider 下三档种子案例均可在 30 秒内出结论
- [ ] 画布演示用 ≥50 节点子图（真实 Esplora 数据更佳）
- [ ] 屏幕分辨率 1920×1080，浏览器缩放 100%，隐藏书签栏
- [ ] 录屏同时收录系统音频（可选轻量 BGM，人声清晰优先）
- [ ] 导出格式 MP4 (H.264)，码率 ≥8Mbps
